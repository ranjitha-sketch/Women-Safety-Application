# 🛡️ Women Safety App

A Women Safety App designed to improve personal security by providing quick access to emergency features, location sharing, and trusted contacts. The application helps users respond to emergency situations through a simple and user-friendly interface.

## Features

- **SOS Alert** – Quickly initiate an emergency alert.
- **Live Location Sharing** – Share your current location with trusted contacts.
- **Emergency Contacts** – Add, manage, and contact trusted people.
- **Fake Call Simulation** – Simulate an incoming call to help users exit uncomfortable situations.
- **Safe Route Navigation** – Support safer travel planning.
- **Emergency Calling** – Quick access to emergency services.
- **Responsive Design** – Works on desktop and mobile devices.

## How to Use

1. Open `index.html` in your browser.
2. Add trusted contacts and their phone numbers.
3. Allow location access when prompted.
4. Use the SOS feature during an emergency.
5. Share your location with trusted contacts when needed.
6. Use the fake call feature when you need a simulated incoming call.

## Files

- `index.html` – Main application interface
- `style.css` – Styling and responsive layout
- `script.js` – Application logic
